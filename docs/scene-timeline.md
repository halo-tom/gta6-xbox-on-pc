# Scene timeline

Dates and events as publicly reported; kept here because the video and the notes refer to
them. No links, no files, no keys.

| Date (2026) | Event |
|---|---|
| 11-10 | digital pre-load opens |
| **11-19** | game releases on PS5 and Xbox Series X\|S; no PC version announced |
| 11-21 | a ~209 GB Xbox Series build (version 1.0.2.1) appears publicly, **without the executable** |
| 11-22 | the executable is promised for Monday 18:00 CET, with a paid poll attached |
| **11-23 14:36 UTC** | the executable is released, about 2.5 h before that deadline |
| 11-23 (same post) | a note posted alongside frames the release as a protest and asks for donations |
| 11-23 evening | a developer livestreams the title reaching its menus at ~15 fps, then publishes a Rust layer the same night |
| 11-23 23:07 UTC | one large project's chat server disappears (~179k members) |
| 11-23 23:47 UTC | that project's repository is deleted; its author announces he has quit |
| **11-24** | the publisher's first takedown notice: that project plus **3,007 forks** |
| 11-24 | other builds report walking in the world, shaders loading, and menus at 30 fps |
| **11-25** | builds clear the prologue and reach the first mission after it |

## What this means for the notes in this repository

- The layer projects move in hours. Anything measured here is a snapshot.
- The takedown that removed the most-starred project named only that project; independent
  projects were not covered by it, but the argument it used could be applied to others.
- Our own measurements started after the executable was public; nothing here depends on
  where it came from.
